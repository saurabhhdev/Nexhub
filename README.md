# Nexhub

Nexhub is a GitHub profile explorer built with React, Vite, and Redux Toolkit.

## Development

```sh
npm ci
npm run dev
```

## Production build

```sh
npm run build
npm run preview
```

The app is published to GitHub Pages at <https://saurabhhdev.github.io/Nexhub/> by the workflow in `.github/workflows/deploy.yml`.
